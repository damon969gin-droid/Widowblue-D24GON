# Agents

Each agent is a modular, sandboxed worker with a single responsibility.

Planned core agents (MVP):

- Coordinatore
- Design
- Frontend
- Backend
- Database
- Media
- Test / QA
- Memoria
- Deploy
- Security
- Research
- Documentation

Agents can be written in TypeScript, Python or any language that can speak the internal protocol.
They run inside the sandbox with limited permissions.
